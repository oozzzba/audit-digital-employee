# 审计整改督办工作要点

> 对齐国家管网审计管理信息系统业务规则（整改问题分类、状态流转、销号红线、台账字段）。

## 一、整改问题分类（推送整改任务时必选其一）

1. **立行立改**：能够在较短时间内立即整改到位的问题。
2. **分阶段整改**：需分阶段推进、限期完成的问题。
3. **持续整改**：一时难以彻底解决、需长期持续跟踪的问题。

问题推送整改任务后，对应底稿即锁定，不允许再修改。

## 二、整改状态与流转

问题状态依次流转：**已下发 → 已分发 → 已反馈整改信息 → 已销号**。

整改执行状态：**尚未开始整改 → 整改中 → 完成整改 / 已采取措施**。

主要流转环节：
1. 整改责任主体录入整改（措施、进展、佐证材料）。
2. 提交审核：审核「同意」则继续流转；「不同意」必须填写意见并退回整改人重录。
3. 提交立项单位复核：复核「通过」则继续流转（转持续整改或销号）；「不通过」填写复核意见退回重改。

## 三、整改台账字段（逐条对应审计问题）

整改台账逐条对应审计报告发现的问题，字段包括：
- 问题编号 / 问题名称 / 问题定性 / 问题类别
- 整改责任部门 / 整改责任人 / 整改状态 / 是否销号 / 整改时限
- 问题原因分析 / 整改措施 / 审计建议
- 整改成果金额（增加收入、挽回资金、减少成本、收回资金、收缴罚款、补缴税款、清理债权债务、调整账目等）
- 审计成果（新建或修订制度、优化或完善流程、促进各类手续办理）
- 实施问责（处理、移送）

## 四、销号红线

1. **未整改完成（尚未开始整改 / 整改中）的问题，一律不得销号。**
2. 销号需经复核通过后方可办理；AI 只生成草稿，不代劳销号。
3. 整改不彻底、走过场的问题应当退回，继续督办。

## 五、督办重点

1. 对涉及资金追回、责任追究的问题重点督办。
2. 对整改期限临近的事项提前提醒。
3. 对整改措施不具体、佐证材料不充分的事项退回完善。
