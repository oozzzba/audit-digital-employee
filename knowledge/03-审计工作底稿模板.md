# 审计工作底稿模板（国家管网）

> 说明：对齐国家管网审计工作底稿模板。底稿分两种——情况底稿（Q）与问题底稿（W），现场实施发现问题时用 W 底稿。

## 一、底稿分类与编号

- **审计情况底稿（Q）**：底稿编号 `Q（情况确认）-XX`，用于对审计事项的事实确认。
- **审计问题底稿（W）**：底稿编号 `W（发现问题）-XX`，用于记录审计发现的问题及定性结论。

## 二、W 问题底稿要素

| 要素 | 说明 |
|------|------|
| 审计项目名称 | 按审计通知书 / 年度计划名称填写 |
| 被审计单位名称 | 单位全称 |
| 审计（调查）事项 | 按审计实施方案确定的事项名称 |
| 问题名称 | 一句话概括问题 |
| 问题描述 | 客观描述问题事实 |
| 查证事实 | 已查证的事实、数据、证据 |
| 法律法规依据 | 逐条引用法规名称、文号、条款 |
| 审计意见/建议 | 定性结论与整改建议 |
| 审计人员 / 编制日期 | 编制人 |
| 复核人员 / 复核日期 | 组长、副组长或主审 |
| 被审计单位意见 | 盖章 + 经办人/负责人签字（跨部门事项所有涉及部门签字） |

## 三、审计工作记录要求

1. **抽审比例**：抽审户数一般不低于被审计单位（含所属单位）个数的 50%。
2. **一事一记录**：审计事项逐项书面记录，一事一记录；审计证据对应多个记录时，附在关系最密切的记录后，并在其他记录上注明。
3. **复核制**：审计工作记录编写完成后，由审计组长或主审复核签字。
4. **完整性**：记录应含审计事项名称及所属会计期间/截止日期、审计步骤和方法、查阅资料名称和数量、专业判断和查证结果。

## 四、质量红线

1. **可追溯**：每项结论须有对应审计证据与法规依据支撑。
2. **客观**：只陈述事实，不加入主观臆断。
3. **一事一记录**：问题单独成稿，规范、清晰、结论明确。
